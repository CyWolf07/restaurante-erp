# Restaurante ERP

Sistema ERP local para restaurante.

## Autoria

Creado por el Ing. Josue Villacorte.

Empresa en desarrollo: Zenith.

## Instalacion

El instalador de Windows se genera en:

```text
desktop/Output/RestauranteERP-Setup.exe
```

Para uso diario, abrir el acceso directo `Restaurante ERP` creado en el escritorio o en el menu Inicio.
