ERP RESTAURANTE - INSTALACION EN PC (SERVIDOR + TABLETS)
========================================================
Autoria: creado por el Ing. Josue Villacorte.
Empresa en desarrollo: Zenith.

OPCION A - INSTALADOR COMPLETO (RECOMENDADO)
--------------------------------------------
1. Doble clic en: Instalar-RestauranteERP.bat
   Clic derecho -> Ejecutar como administrador si lo pide.

2. El instalador descarga e instala automaticamente:
   - PHP 8.3 con extensiones PostgreSQL/Laravel
   - PostgreSQL 16
   - Composer
   - Node.js 20 LTS + pnpm

3. Configura todo:
   - Crea la base de datos
   - Ejecuta migraciones
   - Compila assets del frontend
   - Crea accesos directos en escritorio y menu Inicio

OPCION B - INSTALADOR INNO SETUP
--------------------------------
1. Descarga Inno Setup: https://jrsoftware.org/isinfo.php
2. Abre desktop\setup.iss en Inno Setup -> Compile (F9)
3. El instalador queda en: desktop\Output\RestauranteERP-Setup.exe

USO DIARIO
----------
Doble clic en "Restaurante ERP" desde el escritorio o el menu Inicio.
Abre: http://127.0.0.1:8080/login
Tablets misma WiFi: http://IP-DEL-PC:8080

SOLUCION DE PROBLEMAS
---------------------
1. "PHP no esta en el PATH"
   Ejecuta el instalador completo otra vez.

2. "Migraciones fallaron"
   Verifica que PostgreSQL este corriendo y revisa las credenciales en .env.
   Si aparece "Permission denied" en storage/logs o bootstrap/cache,
   ejecuta "Configurar o actualizar Restaurante ERP" como Administrador.
   Tambien puedes ejecutar:
      powershell -ExecutionPolicy Bypass -File desktop\Reparar-Permisos-RestauranteERP.ps1
   Recomendado: instalar en C:\RestauranteERP, no en C:\Program Files.

3. "Assets no compilados"
   Ejecuta: pnpm install && pnpm run build

4. "Tablets no se conectan"
   Verifica que esten en la misma red WiFi y que el firewall permita el puerto 8080.

5. Warnings de PHP sobre openssl/exif duplicados o bcmath faltante
   Abre php.ini y deja una sola linea extension=openssl y extension=exif.
   Para bcmath, instala/habilita una version de PHP que incluya php_bcmath.dll.
